# Perfil Dev Jr - Teste Técnico Mobile

## Descrição
Este projeto foi desenvolvido em React Native com Expo como parte de um teste técnico simulado para a vaga de Desenvolvedor Mobile Júnior.  
O aplicativo apresenta um perfil profissional com navegação por abas inferiores (TabBar), exibindo informações pessoais, habilidades e projetos.

---

## Tecnologias utilizadas
- React Native
- Expo
- JavaScript
- React Navigation (Bottom Tabs)
- StyleSheet
- Git
- GitHub

---

## Funcionalidades
- Navegação por abas inferiores (TabBar)
- Tela de perfil com foto, nome, cargo e descrição
- Tela de habilidades com lista organizada
- Tela de projetos com portfólio de repositórios
- Tela de contato com formulário simples
- Interface estilizada com cores padronizadas
- Layout responsivo e organizado

---

## Telas do aplicativo

### Perfil
Apresenta informações pessoais como:
- Foto de perfil
- Nome
- Cargo
- Seção "Sobre mim" com descrição profissional

### Habilidades
Lista de habilidades técnicas do desenvolvedor, como:
- React Native
- JavaScript
- Git
- HTML
- CSS

### Projetos / Contato
Exibe uma lista de projetos desenvolvidos durante os estudos, incluindo:
- Aplicações com consumo de API
- Projetos de estudo de navegação
- Aplicações práticas com React Native

Também contém uma área de contato com:
- Campo de e-mail
- Campo de mensagem
- Botão de envio (simulação)

---

## Organização do código
O projeto foi organizado da seguinte forma:

- App.js → Configuração da navegação (TabBar)
- screens/PerfilScreen.js → Tela de perfil
- screens/HabilidadesScreen.js → Tela de habilidades
- screens/ProjetosScreen.js → Tela de projetos
- assets/ → Imagens do projeto

A estrutura foi pensada para facilitar manutenção, leitura e separação de responsabilidades.

---

## Diferenciais
- Interface com cores padronizadas em azul
- Layout moderno com cards e sombras
- Código organizado em componentes separados
- Navegação funcional entre telas
- Estrutura profissional

## Como executar o projeto

1. Clone o repositório:
git clone https://github.com/Luanafollegati/teste-tecnico-dev-jr-mobile.git

2. cd perfil-dev-jr

3. npm i

4. npx expo start
